# StreamFrame studio

StreamFrame is a local editing tool. The source footage is the focal point:
keep playback and trim together, present a short list of moments, and show
only the active editing tool. Sources, Exports, and Live session have their
own views so browsing and monitoring do not crowd the editor.

- Use warm paper or charcoal with green actions and a consistently dark
  media stage. Follow the device theme until the user picks a preference.
  Keep Sources, Exports, and Add source in a left rail on desktop and a
  compact header on small screens. The export template has its own palette.
- Confirm destructive actions and unsaved navigation in a focused dialog.
  Show successful actions as short, dismissible toasts. Keep errors and
  warnings near the controls where people can take action on them.
- Use Aptos for controls, Bahnschrift for display headings where available,
  and tabular digits for times. Use dividers for
  lists and keep metadata, diagnostics, and evidence behind disclosure where
  they are not needed to act.
- Show the ranking score next to every scored moment. Lead review with the
  portrait framing preview when a webcam crop exists. Opening Framing shows
  the source and editable guides; the portrait view approximates framing
  only, and the rendered file remains the final review.
- Name the current source preparation step. Show a percentage only for
  reported analysis progress. Keep the clip timeline separate, with a
  seekable playhead, a highlighted selection, and exact trim fields.
- Use the same export cards in the library and source review. Queued and
  rendering clips appear alongside finished clips with no download action.
  Confirm deletion and missing opening titles before the action proceeds.
- Review uses a divider-based moment index, a central media stage with
  playback and exact trim directly below it, and one open correction tool.
  On narrow screens, keep a compact horizontal moment list above the stage
  and stack the correction panel below trim. Give the panel a display heading
  and keep tool names and descriptions distinct from it. Source details open
  as a reference panel without moving the editor. Review action buttons use text
  labels without decorative icons. Keep exact numeric controls available
  alongside drag controls. Changing tools or views does not remount the
  source player. Source export history opens on demand.
