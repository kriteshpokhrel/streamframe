Privacy policy

Last updated: 22 November 2026

This policy covers the StreamFrame publishing tool ("the tool"), a local desktop application operated by an individual creator to publish their own short-form video clips.

1. What the tool accesses

With the operator's explicit authorization, the tool accesses:

  • The operator's own YouTube channel, through the YouTube Data API v3, limited to the youtube.upload scope. The tool uploads video files and sets that video's title, description, tags and privacy status. It does not read analytics, comments, subscriptions, or any other channel's data.

2. What is stored, and where

Everything stays on the operator's own computer:

  • OAuth credentials (access and refresh tokens) are stored in a local file readable only by the operator's user account (~/.streamframe/publish/credentials.json, mode 0600).
  • Video files are produced and kept locally by the tool until the operator deletes them.
  • A local record of uploads is kept in a SQLite database on the same machine, so the tool does not upload the same clip twice.

The tool sends no data to the developer. It has no analytics, no telemetry, no advertising, and no servers of its own.

3. How data is shared

Video files and their metadata are transmitted to YouTube because publishing them is the requested action. No data is sold, rented, or shared with any other third party. The tool does not use Google user data to train models, does not use it for advertising, and does not transfer it to anyone else.

4. Retention and deletion

Tokens are retained until the operator removes them. The operator can revoke the tool's access at any time at myaccount.google.com/permissions, and can delete the local credential file and upload records at any time. Revoking access does not delete videos already published to YouTube; those are deleted from YouTube Studio.

5. Google and YouTube terms

By using the tool, the operator agrees to the YouTube Terms of Service.

Use of Google user data is also governed by the Google Privacy Policy. The tool's use of the YouTube API Services is subject to the YouTube API Services Terms of Service.

6. Children

The tool is not directed at children and is not offered to the public.

7. Changes

Material changes to this policy will be published on this page with an updated date.
